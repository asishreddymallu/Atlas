# Cache lab programs

Deterministic programs for the Cache tab (generated by `gen_bench.py`, E8). They
take no input and end by running off the end of the program. The `addi x0, x0, 0`
lines are padding, so all five processors compute the same addresses and the L1
counts are the same on every processor.

| Program | What it does |
| --- | --- |
| `stride_1.s`, `stride_2.s`, `stride_4.s`, `stride_8.s`, `stride_16.s`, `stride_32.s` | One load sweep over a 1024-word array at the given stride (in words): spatial locality. |
| `temporal_repeat.s` | A 64-word (256 B) array swept 4 times at stride 1: reuse after the first sweep. |
| `matmul_ijk.s` | 8x8 word matrix multiply, i-j-k: the inner loop walks a row of A and a column of B. |
| `matmul_jik.s` | The same with the two outer loops swapped. |

How to run one:
1. Open it.
2. In the Cache tab, pick a **Lab setup** (for example `dm256`, the Lab 4 base
   setup). This sets L1 and a 1 ms step delay.
3. Press **Run** and watch the L1 Cache sub-tab's live view fill set by set.
4. When it finishes, **Export lab record...** saves the setup and the results as
   JSON.

The presets, the measured hits / misses / evictions for every preset and
program the lab uses, and the record's schema are in
[docs/cache_lab.md](../../docs/cache_lab.md).
